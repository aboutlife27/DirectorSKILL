# 剧情到视觉决策编译器

叙事任务在写导演手册或分镜前读取本文件。目标是从剧情证据推出唯一首选方案，而不是按类型套一组漂亮镜头。

## 1. 导演读法

先完成以下字段；缺失信息可从文本推断，但要把推断标为假设。

| 字段 | 问题 | 合格答案 |
|---|---|---|
| `dramatic_function` | 本场使全片发生什么变化？ | `女儿无法再隐瞒病情` |
| `turn` | 哪个可观察事件使局面不可逆？ | `诊断书被放到桌上` |
| `pov` | 观众的感知依附谁？ | `女儿，直到父亲先读懂结果` |
| `audience_information` | 观众相对人物早知、同知还是晚知？ | `比父亲早十秒确认秘密` |
| `power_in/out` | 权力由谁转向谁？ | `审讯者 → 嫌疑人` |
| `objective` | 主体当下想得到什么？ | `在不说谎的情况下结束晚餐` |
| `obstacle` | 什么阻止目标？ | `父亲的日常关心迫使她留下` |
| `tactic` | 主体如何绕开阻碍？ | `用吃面和整理包来拖延` |
| `subtext` | 对话表面以下真正发生什么？ | `双方都在保护对方` |
| `pressure_delta` | 压力如何变化？ | `缓升，物证出现时跳变` |
| `visible_behavior` | 什么动作能承载上述变化？ | `筷子停住；文件没有递出，只被看见` |

抽象词不能直接进入分镜。把“悲伤”编译为呼吸、停顿、视线、距离、遮挡、动作受阻、声音缺失或环境反应。

## 2. 八条证据轴

每轴取 `-2..+2`，只比较候选原型，不伪装成客观审美测量。

| 轴 | -2 | +2 | 主要影响 |
|---|---|---|---|
| 视点依附 | 观察式 | 强主观 | POV、反应优先级、景深 |
| 权力变化 | 稳定 | 剧烈翻转 | 高度、同框关系、尺度迁移 |
| 信息控制 | 公开 | 强信息差 | 插入、遮挡、揭示时机 |
| 亲密距离 | 疏离 | 高亲密 | 焦段、机距、表演细度 |
| 动能 | 静止 | 高速 | 支撑、运动、切速 |
| 时间压力 | 充裕 | 倒计时 | ASL、动作重叠、声音节拍 |
| 不确定性 | 明确 | 模糊 | 画外空间、负空间、主观声 |
| 现实感 | 仪式化 | 观察式 | 光线修饰、机位自觉、调度自然度 |

## 3. 场景原型

选择原型是选择观众关系，不是选择类型。

| 原型 | 核心判断 | 默认覆盖语法 |
|---|---|---|
| 建立 | 观众需要先学会空间或常态 | 可读主镜头 + 关系镜头 + 一个规则细节 |
| 亲密 | 未说出口的微小行为比事件重要 | 同框优先，少切，反应晚于行为 |
| 对峙 | 双方公开争夺位置或决定权 | 关系主镜头 → 不对称单人覆盖 → 权力重构 |
| 审讯 | 一方控制问题，另一方控制信息 | 轴线稳定；尺度与负空间随信息权转移 |
| 谈判 | 双方不断改换策略 | 保留双人空间，切点落在策略变化而非台词轮次 |
| 揭示 | 已存在的信息改变意义 | 反应或因果载体先于解释，禁止装饰性推近 |
| 发现 | 角色主动拼合线索 | 视线 → 线索 → 新关系，保持空间可追踪 |
| 决定 | 内在选择成为外在行动 | 限制覆盖，动作完成时才改变画面规则 |
| 追逐 | 目标、阻碍和方向必须持续可读 | 地理重锚 → 推进 → 障碍 → 代价 |
| 旅程 | 状态变化来自路程而非单一事件 | 重复构图产生差异，环境运动承担时间 |
| 氛围 | 世界状态本身是叙事信息 | 分层画内运动、声音桥、少量锚点 |
| 转化 | 人或世界跨过不可逆阈值 | 先重复既有语法，再有一次结构性破例 |
| 余波 | 后果比动作更重要 | 延迟切点、留空、恢复或拒绝恢复旧构图 |

## 4. 评分与置信度

1. 根据导演读法写出八轴值和证据短句。
2. 只选 3–5 个合理候选；每个候选按与证据轴的匹配度给 `0..100`。
3. 最高分为唯一首选；记录第二名但默认不展示。
4. `confidence = 最高分 - 第二名`。分差 `>= 20` 为高，`10..19` 为中，`< 10` 为低。
5. 高、中置信度直接执行。低置信度时，若两方案可以合并为“主原型 + 次要机制”则直接合并；不能合并才请求用户选择。

禁止用用户给出的导演姓名加分。姓名只能触发对相关功能方法的检索，最终理由仍须回到剧情证据。

## 5. 原型到视觉策略

按以下顺序编译，后项不能推翻前项：

1. **观众关系**：早知、同知、晚知；依附谁；何时转移。
2. **调度**：人物、道具、门窗和画外空间如何表达权力与阻碍。
3. **覆盖语法**：主镜头、关系镜头、反应、POV、插入和余波的必要集合。
4. **构图与尺度**：谁拥有中心、稳定、空间和清晰度；尺度何时变化。
5. **焦段与机距**：先守项目焦段族；改变透视必须有叙事理由。
6. **相机行为**：锁定、摇移、推拉、手持中只选一个主行为；运动必须对应信息或权力变化。
7. **光与颜色**：继承颜色角色与动机光；只改变色彩弧变量，不逐场换滤镜。
8. **声音与剪辑**：用声音预告、延迟或反驳画面；切点优先服务情绪、故事与节奏。

### 功能方法库

- **信息悬念**：先决定观众相对角色的知情位置，再决定遮挡、POV、反应与揭示镜头。
- **渐进压迫**：在全片弧上逐步改变焦段、机位高度、人物头顶空间和背景压缩，禁止一场内突然全换。
- **色彩写作**：为人物、观念、危险或代价分配颜色角色；颜色出现、污染、消失和回归都必须对应剧情状态。
- **分层运动**：主体动作、背景动作、天气或烟尘分层，任何层的运动都要帮助读清冲突。
- **空间表演**：权力关系可在同框内读清时，优先用调度、景深和遮挡，避免把表演切碎。
- **情绪剪辑**：冲突时按情绪、故事、节奏、视线、二维构图、三维连续性的顺序取舍。

## 6. 冲突解决

优先级为：

`剧情证据 > 项目视觉宪法 > 当前视觉弧位置 > 场景原型 > 用户的功能偏好 > 类型默认 > 通用默认`

当用户提出多个导演姓名：

1. 不混合完整风格包。
2. 把每个名字翻译为用户实际需要的功能，例如颜色角色、精确机位、对称压力。
3. 只采纳服务本场戏剧目标且不破坏视觉宪法的功能。
4. 输出功能理由，不声称复制某位导演的独特风格。

## 7. 输出合同

自动选择块固定为：

```yaml
direction_decision:
  primary_archetype: 审讯
  secondary_mechanism: 揭示
  confidence: 24
  decisive_evidence:
    - 观众必须比审讯者早十秒确认秘密
    - 权力在中段从审讯者转向嫌疑人
    - 对话表面平静，动作和负空间承担冲突
  audience_relation: 先依附审讯者，线索出现后转向嫌疑人
  governing_rule: 谁掌握信息，谁获得稳定构图和更完整的空间
```

其后给出唯一视觉方案。若调用项目状态，则每项标明 `继承`、`弧变化` 或 `已登记破例`。
